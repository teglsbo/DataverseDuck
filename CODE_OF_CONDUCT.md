# Code of Conduct

We follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
In short: be respectful, accept constructive feedback, and don't harass anyone.

Report unacceptable behavior to [@teglsbo](https://github.com/teglsbo) via GitHub —
either a public issue for minor matters, or a direct GitHub message for anything more
sensitive. Reports are handled privately and fairly.
